# Notas tecnicas de mapas - Borrador 2 PolosGastro

> Fase 7. No se regeneraron mapas en esta etapa. Estas notas orientan una futura revision
> cartografica y evitan que los visuales actuales se interpreten como delimitaciones oficiales.

## Criterios para la proxima version de mapas

- `mapa1_universo_por_grupo.png` debe rehacerse sin etiquetas combinadas ni lecturas que sugieran
  poligonos oficiales.
- Palermo debe leerse como un nucleo territorial con subpolos: Palermo Soho, Palermo Hollywood y
  Las Canitas. No debe aparecer como tres nucleos equivalentes a Puerto Madero, San Telmo o Recoleta.
- Belgrano debe manejarse como macroarea con subzonas de distinto estado documental: Barrio Chino
  como subzona con mejor respaldo, y Bajo Belgrano / Belgrano R como casos a validar o de anexo.
- `mapa3_relevantes_y_emergentes.png` debe separar visualmente emergentes con documentacion media
  de candidatos debiles o a validar.
- Los mapas deben evitar parecer delimitaciones oficiales de polos gastronomicos.
- Se recomienda usar barrios tenues como contexto y puntos, halos o marcas aproximadas para
  subpolos, corredores o zonas.
- `mapa5_revision_documentacion.png` debe quedar como material interno de trabajo, no como visual
  publico.
- El documento semilla puede orientar puntos o halos futuros, pero no debe usarse para delimitar
  poligonos ni para confirmar densidad.

## Advertencia metodologica para todo mapa futuro

Los barrios y comunas oficiales pueden usarse como referencia de ubicacion. No representan el limite
del polo gastronomico. Para corredores o subpolos sin delimitacion textual robusta, corresponde
marcar aproximacion o dejar el caso como pendiente.

## Recomendacion operativa

Antes de rehacer mapas, conviene cerrar una tabla de estilo cartografico con tres capas:

1. Barrios / comunas oficiales como base tenue.
2. Puntos o halos aproximados para subpolos y corredores.
3. Etiquetas metodologicas visibles para casos debiles, pendientes o de uso interno.

No se recomienda generar nuevos mapas en esta fase sin revisar primero el script especifico de
PolosGastro y el criterio de publicacion de cada visual.
