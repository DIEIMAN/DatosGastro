# Arquitectura del informe completo — 22 zonas (V4.1)

**Fecha:** 2026-07-12  
**Rol secundario:** arquitecto_editorial_informe_completo  
**Premisa:** el encargo de 22 referencias **no** implica 22 polos equivalentes.

## 1. Problema editorial

Hay:

- **7** delimitaciones ya desarrolladas (universo cerrado).  
- **15** candidatas de expansión con resultados espaciales futuros heterogéneos.

Si el informe trata a todas como "polos", se rompe la metodología y la credibilidad.

## 2. Principio de cobertura del encargo

Toda referencia encomendada **aparece** en el producto, con un **estatus explícito**:

| Estatus | Ejemplo de lenguaje |
|---|---|
| Polo / corredor adoptado | "Delimitación adoptada…" |
| Área asociada / subpolo | "Área asociada a…" |
| Microcentralidad | "Microcentralidad de…" |
| Zona multinodo | "Varios nodos en…" |
| Transición | "Zona de transición entre…" |
| Oferta dispersa | "Oferta gastronómica dispersa…" |
| Evidencia insuficiente | "Incluida en el encargo; evidencia insuficiente para delimitación" |

## 3. Alternativas de producto

| Opción | Pros | Contras |
|---|---|---|
| A. Ejecutivo breve + anexo atlas | Decisiones arriba; detalle abajo | Dos piezas a mantener |
| B. Informe único extenso | Una sola pieza | Difícil de leer para jefatura |
| C. Político + atlas territorial | Separa decisión y mapa | Riesgo de desalineación |
| D. Solo fichas por zona | Homogéneo | Pierde narrativa integrada |

### Recomendación principal: **A + C híbrido**

1. **Informe político-ejecutivo** (corto): propósito, método, mapa general, decisiones, riesgos.  
2. **Atlas territorial / anexo**: fichas de las 22 referencias agrupadas por estatus, no por "todos polos".  
3. **Capítulo metodológico** reutilizable para actualización.

## 4. Estructura modular propuesta

1. Propósito y mandato (22 referencias del encargo).  
2. Metodología híbrida (espacial primero; documental post hoc).  
3. Mapa general de estatus (leyenda por taxonomía).  
4. Siete delimitaciones desarrolladas (resumen + remisión).  
5. Resultados adoptables de expansión (solo los que pasen criterio).  
6. Corredores y microcentralidades.  
7. Áreas asociadas y transiciones.  
8. Zonas multinodo (p.ej. Caballito si aplica).  
9. Oferta dispersa / evidencia insuficiente (siguen en el encargo).  
10. Ficha única de las 22 (tabla maestra).  
11. Actualización futura y datos abiertos.

## 5. Ficha tipo (campos mínimos)

- Nombre canónico  
- Estatus  
- Forma territorial  
- Evidencia espacial (sí/no/parcial)  
- Evidencia documental (fuerza)  
- Relación con vecinos / polos adoptados  
- Lenguaje público autorizado  
- Limitaciones  
- Próxima revisión  

## 6. Qué no diseñar aún

- PDF final  
- Mapas editoriales nuevos de las 15  
- Ranking político de "mejores polos"

## 7. Dependencia de Codex

Las secciones 5–9 se rellenan con resultados de Tandas 1–4.  
Esta arquitectura puede publicarse como **marco** antes de tener todos los resultados.
