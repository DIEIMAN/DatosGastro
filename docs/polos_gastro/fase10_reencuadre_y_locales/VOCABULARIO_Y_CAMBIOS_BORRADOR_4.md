# Vocabulario y cambios necesarios para Borrador 4

Fecha de trabajo: 2026-07-02. Documento interno de preparacion para reencuadrar el lenguaje de
PolosGastro. No aplica cambios sobre Borrador 3 ni sobre tablas existentes.

## 1. Criterio editorial

Borrador 4 debe abandonar el lenguaje de admision o descarte. Todos los polos presentes en el
documento semilla forman parte del universo operativo de trabajo. La redaccion debe distinguir nivel
de documentacion, relevancia, necesidad de ampliacion y oportunidades de gestion.

## 2. Reemplazos recomendados

| Lenguaje anterior | Problema | Lenguaje nuevo recomendado | Uso |
| --- | --- | --- | --- |
| No incluir | Sugiere descarte del universo y contradice el nuevo criterio semilla. | Documentacion publica a reforzar | Para polos que siguen en el universo pero requieren mejores fuentes publicas. |
| En espera de evidencia | Puede leerse como duda sobre la pertenencia del polo. | Informacion complementaria pendiente | Para casos donde falta documentacion o detalle territorial. |
| Candidato debil | Jerarquiza negativamente y puede sonar a exclusion. | Polo del universo semilla con documentacion publica acotada | Para casos validos del universo con respaldo documental limitado. |
| Validar si es polo | Plantea una decision binaria que esta superada por el nuevo criterio. | Complementar documentacion y relevancia | Para investigaciones posteriores por polo. |
| Ranking | Induce lectura competitiva u ordinal. | Lectura orientativa | Para tablas comparativas o agrupamientos editoriales. |
| Densidad real | La fuente disponible no mide densidad real ni actividad actual. | Senal territorial de contexto | Para F01/F02, capa objetiva o presencia relativa. |
| Entra al cuerpo / no entra | Convierte el informe en filtro de inclusion. | Ubicacion editorial sugerida | Para decidir cuerpo, fichas o anexo. |
| Descartado | Contradice el universo semilla y puede borrar casos de interes del area. | Requiere ampliacion documental | Para casos con baja documentacion publica. |
| No valida | Puede sonar a negacion del polo. | No alcanza para cerrar delimitacion o vigencia | Para fuentes que aportan contexto pero no prueban limites ni actividad actual. |
| Locales activos | La fuente no verifica actividad actual. | Locales mencionados / referencias gastronomicas preliminares | Para locales del documento semilla. |
| Prueba de polo | Sobrestima listados de locales o fuentes periodisticas. | Insumo para descripcion y fichas | Para menciones cualitativas o listados de referencias. |
| Area oficial | Puede sugerir delimitacion institucional inexistente. | Area de trabajo / recorte territorial preliminar | Para mapas y fichas no oficiales. |

## 3. Nueva clasificacion editorial propuesta

Esta clasificacion se propone para Borrador 4. No modifica todavia tablas existentes.

| Nueva clasificacion editorial | Uso sugerido |
| --- | --- |
| Polo principal consolidado | Polos de alta centralidad en el relato institucional, con documentacion fuerte o reconocimiento urbano claro. |
| Polo relevante consolidado | Zonas con respaldo suficiente para formar parte del cuerpo, aunque sin el peso editorial de los principales. |
| Polo emergente o en expansion | Casos con interes territorial, documentacion media o dinamica reciente a profundizar. |
| Polo especifico / corredor / subzona | Ejes, subzonas o areas de alcance acotado que requieren redaccion territorial cuidadosa. |
| Polo con documentacion publica a reforzar | Casos del universo semilla con baja evidencia publica, sin que eso implique descarte. |
| Polo incorporado por investigacion complementaria | Categoria futura para casos que no estan en el documento semilla y que solo podrian sumarse con decision humana y trazabilidad. |

## 4. Mapeo inicial orientativo

| Lectura de Borrador 3 | Mapeo sugerido para Borrador 4 | Nota |
| --- | --- | --- |
| Area nucleo | Polo principal consolidado | Mantener advertencias de no delimitacion oficial y no padron. |
| Zona relevante | Polo relevante consolidado | Diferenciar macroareas y subzonas cuando corresponda. |
| Emergente con documentacion media | Polo emergente o en expansion | Evitar presentar como consolidado si falta delimitacion o vigencia. |
| Candidato a validar - documentacion debil | Polo con documentacion publica a reforzar o polo especifico/subzona | Elegir segun el caso, sin lenguaje de descarte. |
| Anexo / caso secundario | Polo especifico / corredor / subzona | Puede ir en fichas o anexo, no como exclusion. |
| En espera de evidencia | Polo con documentacion publica a reforzar | Reemplazo recomendado para el nuevo enfoque. |

## 5. Cambios necesarios antes de redactar Borrador 4

- Reescribir la metodologia para declarar que el documento semilla define el universo operativo.
- Cambiar los estados que suenan a filtro de entrada por estados de documentacion y ubicacion
  editorial.
- Tratar la capa objetiva como contexto, no como filtro ni ranking.
- Mantener las referencias de locales como preliminares y obligatorias para la capa de puntos, no
  como prueba de vigencia.
- Reservar Google Places para geolocalizacion y enriquecimiento interno, con revision manual.
- Evitar "DataGastro" como marca publica visible; usar DGDGAS - Direccion General de Gastronomia
  cuando se prepare una pieza externa.
