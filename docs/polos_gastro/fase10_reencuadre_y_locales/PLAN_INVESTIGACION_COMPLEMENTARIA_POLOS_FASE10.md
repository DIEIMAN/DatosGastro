Fecha de trabajo: 2026-07-02. Documento interno de planificacion. No se realizaron busquedas web
nuevas en esta fase.

## 1. Objetivo

Preparar una estrategia de busqueda para fortalecer la documentacion publica, la descripcion
territorial y la capa de locales por polo. La investigacion complementaria no decide si un polo
existe: todos los polos del documento semilla forman parte del universo operativo.

## 2. Tipos de fuentes deseables

- Paginas oficiales de GCBA, Turismo BA, Cultura BA, BA Data y organismos publicos.
- Notas periodisticas accesibles y trazables.
- Guias gastronomicas o medios especializados con fecha y autor identificables.
- Reconocimientos gastronomicos externos, solo si se cita la fuente primaria.
- Documentacion barrial, turistica o cultural que ayude a describir el recorte.
- Fuentes privadas solo como referencia cualitativa, nunca como dataset oficial ni scraping.

## 3. Queries base

Usar combinaciones como:

- `[polo] polo gastronomico Buenos Aires`
- `[polo] restaurantes destacados`
- `[polo] circuito gastronomico`
- `[polo] gastronomia CABA`
- `[polo] nota gastronomica`
- `[local destacado] restaurante Buenos Aires`
- `[local destacado] premios restaurante Buenos Aires`
- `[local destacado] reconocimiento internacional`

Para Palermo, casos como Don Julio deben documentarse con fuentes externas verificables si se
menciona reconocimiento internacional. No alcanza con el documento semilla.

## 5. Criterios de cierre de busqueda

Para cada polo, registrar:

- fecha de consulta;
- fuente;
- URL;
- tipo de fuente;
- que aporta;
- que no aporta;
- limitaciones;
- si puede citarse en cuerpo, ficha o anexo.

Si no se encuentra informacion suficiente, redactar con prudencia: "polo del universo semilla con
documentacion publica a reforzar" o "informacion complementaria pendiente". No usar "descartado",
"no incluir" ni "no entra".
