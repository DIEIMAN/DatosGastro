# Paquete Fase 26 - Revision comparativa de cartografia

Este paquete reune el material de lectura para revisar la evolucion antes/despues de la cartografia experimental de polos y microzonas gastronomicas.

## Contenido

- `INFORME_FASE26_COMPARATIVA_CARTOGRAFIA.md`: documento principal.
- `tabla_evolucion_cartografia_fase26.csv`: tabla de etapas y usos recomendados.
- `comparativas_png/`: siete laminas comparativas antes/despues.
- `mapas_v4_2_recomendados/`: mapas v4.2 para revision interna.
- `anexos_tecnicos/`: QA visual tecnico como anexo.

## Lectura recomendada

1. Abrir el informe principal.
2. Revisar `comparativa_general_antes_despues.png` y `comparativa_decision_v3_v4_2.png`.
3. Revisar Palermo y San Telmo como casos de mejora de lectura.
4. Revisar Belgrano, Corrientes/Microcentro y Caballito con cautela: mejoran visualmente, pero requieren redibujo urbano fino.
5. Usar el QA tecnico solo como control interno.

## Advertencias de uso

La v4.2 es cartografia experimental mejorada. No es cartografia institucional final, no define limites oficiales y no acredita actividad actual de establecimientos. El paquete no contiene datos crudos, identificadores tecnicos de proveedor, JSON de proveedor ni carpetas de uso restringido.

## Confirmacion operativa

Paquete creado sin llamadas a API, sin nuevas consultas a Google Places, sin commits, sin push y sin staging.
