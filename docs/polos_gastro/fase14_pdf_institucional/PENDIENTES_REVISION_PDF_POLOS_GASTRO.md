## Secciones que pueden recortarse

- Anexos metodologicos, si el destino es lectura de conduccion.
- Paginas de detalle territorial, si se necesita una version ejecutiva breve.
- Hallazgos de capa auxiliar, si se decide dejar el detalle en respaldo interno.
- Recomendaciones y proximos pasos, si se prepara una version mas institucional y menos operativa.

## Decisiones que bloquean la version final

- Validacion de delimitaciones Corrientes / Abasto.
- Criterio de publicacion de puntos y nombres de locales.
- Tratamiento de duplicados, cadenas y sedes a revisar.
- Nivel de exposicion de Belgrano y subzonas.
- Inclusion o exclusion del mapa interno general de revision.
- Definicion de si el entregable final es PDF, DOCX editable o ambos.

## Falta para generar la version final

- Revision humana del PDF actual.
- Confirmacion de criterios con Ale.
- Ajuste o regeneracion final de mapas.
- Nueva rasterizacion completa del PDF final.
- QA de privacidad y marca sobre la version final.
- Renombrar el archivo final sin etiqueta de trabajo, si se aprueba para circulacion.
