# Cambios V1 a V2 - PolosGastro DGDGAS

## Qué mejoró respecto a la versión preliminar anterior

- Se mantuvo la estructura general de 18 páginas.
- Se conservó el mapa global de 22 polos/ejes como mapa principal.
- Se rediseñaron las páginas de detalle territorial para que no dependan de recortes grandes de mapas.
- Los mapas de detalle ahora son más limpios, con puntos y símbolos más grandes.
- Los nombres de locales se trasladaron a cajas laterales para evitar saturar el mapa.
- Cada página de detalle incluye: mapa, menciones destacadas, lectura territorial y nota de cautela.
- Se agregó una tabla específica de menciones destacadas por polo/subzona.
- Se agregó una página de criterio de menciones para separar incluidos, a validar y excluidos.

## Mapas rediseñados

Se rediseñaron las cinco páginas de detalle:

- Palermo / Las Cañitas.
- Puerto Madero.
- San Telmo.
- Corrientes / Abasto.
- Belgrano y subzonas.

El mapa global no se rediseñó: se conserva porque funcionaba como lectura principal del universo semilla.

## Casos excluidos por prudencia

No se incorporan como destacados visibles:

- Osaka.
- Aldo's.
- Las Pizarras Bistro.

- Morelia.

Motivos principales: vigencia no confirmada, búsqueda a corregir, duplicado probable, sede no resuelta o falta de correspondencia gastronómica suficiente.

## Qué mapas siguen débiles

- **Corrientes / Abasto:** Corrientes queda más claro como eje, pero Abasto sigue dependiendo de refuerzo documental y no debe forzarse con puntos propios.
- **Belgrano:** mejora como macroárea y separa subzonas, pero requiere validación humana antes de una versión operativa.
- **Puerto Madero:** mejora visualmente, aunque varias menciones necesitan confirmación de sede o zona.
